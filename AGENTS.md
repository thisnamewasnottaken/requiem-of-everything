# Agent instructions

Always consider desktop, tablet, and phone layouts and both touch and keyboard input when planning, implementing, and reviewing changes.

For every UI change, verify the affected experience at desktop, tablet, and phone widths using the affected UI's existing breakpoints. Check touch targets and applicable gestures, and make sure essential actions don't require hover. Check logical keyboard focus order, visible focus, and affected keyboard shortcuts. Record what you verified in the PR and include relevant tests or screenshots.

See the [contributor acceptance checklist](CONTRIBUTING.md#ui-acceptance-checklist).
